# ⚡ Next.js AI Chatbot Starter (UPI & Multi-Model Ready)

A clean, responsive AI chat template built with Next.js 14, Tailwind CSS, and the Vercel AI SDK. Pre-configured to route across **GPT-4o, Claude 3.5 Sonnet, DeepSeek, and Sarvam Indic** using a single API key.

## 🚀 Quick Start

1. **Clone the repo:**
   ```bash
   git clone [https://github.com/your-username/nextjs-ai-chatbot-starter.git](https://github.com/your-username/nextjs-ai-chatbot-starter.git)
   cd nextjs-ai-chatbot-starter
   npm install
